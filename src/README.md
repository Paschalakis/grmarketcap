# Πηγαίος κώδικας του Axiogram

Το `index.html` στη ρίζα φτιάχνεται από αυτά τα αρχεία:

    python3 build.py      # γράφει το repo/index.html

- `body.html`: η σελίδα (HTML, CSS, JavaScript)
- `agora-athinon.html`: η κεφαλίδα (τίτλος, γραμματοσειρές, βασικά χρώματα)
- `quotes.csv`: αρχικές τιμές για όταν δεν φορτώνουν τα δεδομένα
